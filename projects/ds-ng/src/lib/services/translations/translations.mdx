      # Translations service
    </div>

    ## {DESCRIPTION_TITLE}

    <blockquote>
      <p>
        The Translations Service is responsible for managing and providing translations for different languages within the application.
      </p>
      <p>
        It allows developers to easily retrieve translated strings based on the user's selected language, ensuring a localized experience.
      </p>
    </blockquote>
    <br />
    ## {SPECIAL_SPECIFICATIONS_TITLE}

    <blockquote>
      ### ⚙️ Service methods

      <ul>
        <li>***getTranslation(key: string): string***: This method retrieves the translated string for the given key, if the translation does not exist, it returns the key itself.</li>
        <li>***setLanguage(languageCode: string): void***: This method sets the current language for translations.</li>
        <li>***getCurrentLanguage(): string***: This method returns the currently set language code.</li>
        <li>***updateDictionary(lang: string, dictionary: BmbDictionaries): void***: This method updates the translation dictionary for a specific language.</li>
        <li>***addDictionary(lang: string, dictionary: BmbDictionaries): void***: This method adds a new translation dictionary for a specific language.</li>
      </ul>

      ### ⚙️ Usage

      <p>
        To use the Translations Service, inject it into your component or service and call the desired methods to retrieve translations.
      </p>
      <br />

      #### 🟣 Get translations from a pipe

      <Source code={`import { TranslatePipe } from '@ti-tecnologico-de-monterrey-oficial/ds-ng';

      @Component({
        selector: 'app-component',
        imports: [
          ...,
          TranslatePipe,
        ],
        ...
      })

      <!-- In your template -->
      <p>{{ 'greeting.hello' | translate }}}</p>


      `} />

      #### 🟣 Get translations of a conditional string

      <Source code={`import { TranslationsService } from '@ti-tecnologico-de-monterrey-oficial/ds-ng';

        constructor(private translationsService: BmbTranslationsService) {}

        conditionalString(state) {
          switch(state) {
            case 'success':
              return this.translationsService.getTranslation('operation.success');
            case 'error':
              return this.translationsService.getTranslation('operation.error');
            default:
              return this.translationsService.getTranslation('operation.unknown');
          }
        }

        `}
      />

      #### 🟢 Set and get current language

      <Source code={`import { TranslationsService } from '@ti-tecnologico-de-monterrey-oficial/ds-ng';

        constructor(private translationsService: BmbTranslationsService) {}

        setLanguage(languageCode: string): void {
          this.translationsService.setLanguage(languageCode);
        }

        getCurrentLanguage(): string {
          return this.translationsService.getCurrentLanguage();
        }
      `} />

      #### 🔵 Update and add translation dictionaries

      <blockquote class="markdown-alert-warning">
        ### {RELEVANT_TITLE.warning.replaceAll('*', '').replaceAll('<br/>', '')}

        <p>
          The update and add dictionary methods should be used with caution to avoid overwriting existing translations or introducing inconsistencies.
        </p>
        <p>
          The dictionary update method does not deep clone the provided dictionary, so any nested objects will be referenced rather than copied.
        </p>
      </blockquote>
      <br />

      <blockquote class="markdown-alert-note">
        ### {RELEVANT_TITLE.important.replaceAll('*', '').replaceAll('<br/>', '')}

        <p>
          You can use the Bamboo json files located in the <code>@ti-tecnologico-de-monterrey-oficial/ds-ng/assets/i18n</code> folder as a reference for creating or updating translation dictionaries.
        </p>
      </blockquote>

      <Source code={`import { TranslationsService } from '@ti-tecnologico-de-monterrey-oficial/ds-ng';

        constructor(private translationsService: BmbTranslationsService) {}

        updateDictionary(lang: string, dictionary: BmbDictionaries): void {
          this.translationsService.updateDictionary(lang, dictionary);
        }

        addDictionary(lang: string, dictionary: BmbDictionaries): void {
          this.translationsService.addDictionary(lang, dictionary);
        }
      `} />
