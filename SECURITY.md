# Security Policy

## Supported Versions

Las siguientes versiones del sistema están actualmente soportadas. Se recomienda utilizar siempre la versión más reciente para garantizar la recepción de actualizaciones de seguridad y soporte técnico. Las versiones anteriores a la 1.4.x ya no reciben mantenimiento ni correcciones de seguridad.

| Version | Supported          |
| ------- | ------------------ |
| 1.5.x   | :white_check_mark: |
| < 1.4.x | :x:                |

## Reporting a Vulnerability

Si encuentras un bug o vulnerabilidad de seguridad, por favor repórtalo en la sección de [issues](https://github.com/ti-tecnologico-de-monterrey-oficial/tec-design-system-ng/issues) con una descripción detallada del problema, los pasos para reproducirlo y cualquier información relevante. Nos comprometemos a investigar y responder a los reportes en el menor tiempo posible. No divulgues públicamente los detalles hasta que el equipo haya dado una respuesta y, si corresponde, publicado una solución.
