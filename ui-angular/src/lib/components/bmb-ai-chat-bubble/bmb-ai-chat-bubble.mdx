## Solicitudes de carga de archivos

El tipo `BmbUploadFileMessage` forma parte de `BmbChatMessage` con el discriminante
`type: 'upload-file'`. Su renderer `BmbUploadFileMessageComponent` también se
exporta para uso independiente.

```typescript
const message: BmbUploadFileMessage = {
  id: 'upload-service-file',
  type: 'upload-file',
  timestamp: new Date(),
  isUser: false,
  content: {
    fileName: 'nombre de archivo de servicio',
    acceptedFormats: ['.pdf', '.doc', '.xml'],
    maxFileSize: '10 MB',
    additionalRequirements: ['El documento debe ser legible.'],
  },
};
```

```html
<bmb-ai-chat-bubble
  [message]="message"
  [showActions]="false"
  (uploadFileRequested)="handleUploadRequest($event)"
/>
```

El evento `BmbUploadFileRequestEvent` contiene `messageId`, `message` y
`nativeEvent`. La aplicación consumidora abre el selector y gestiona la
validación y la carga. Los formatos y el tamaño son únicamente informativos:
este componente no selecciona ni sube archivos.

`acceptedFormats` valida su configuración al recibir o actualizar el mensaje:
cada elemento debe ser una extensión con punto inicial (`.pdf`, `.tar.gz`) o un
tipo MIME sin parámetros (`application/pdf`, `image/png`). También se admiten
`image/*`, `audio/*` y `video/*`. No se admiten espacios, listas separadas por
comas dentro de un elemento ni extensiones sin punto. Los valores inválidos
lanzan un error construido con `buildErrorMessage`. Esta validación verifica
la sintaxis, no la existencia de un subtipo MIME en un registro ni los archivos.
Una lista vacía o ausente sigue siendo válida.

`text`, `buttonLabel` y `cancelKeyword` permiten personalizar los textos.
El botón siempre está habilitado. Sin requisitos se oculta esa sección.
Los textos predeterminados usan el servicio de traducciones en español e inglés.
La instrucción de escribir **Cancelar** no cancela automáticamente la
conversación: la aplicación debe procesar esa respuesta desde la barra de chat.
