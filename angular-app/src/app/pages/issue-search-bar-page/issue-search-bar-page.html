Issue original

Al buscar "David Medina" escribiendo rápido, la búsqueda se disparaba demasiado pronto tras "David", impidiendo continuar con "Medina". El debounce estaba fijo en 300 ms dentro del componente, sin forma de ajustarlo según la velocidad de respuesta del backend que consume cada implementación.

Solución: se agregó el input searchDebounceTime (por defecto 300 ms) para que cada consumidor del componente pueda ajustar el tiempo de espera antes de filtrar, usando toObservable + switchMap para reaccionar a cambios en caliente de ese valor. Prueba moviendo el slider de arriba y escribiendo "David Medina" en el campo.
