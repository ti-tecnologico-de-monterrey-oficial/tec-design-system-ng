Prueba enviar con Enter, adjuntar o arrastrar archivos, cambiar el bot, activar el micrófono y alternar los estados desde las propiedades.

Escenarios de prueba

  • Escribe un mensaje y envíalo con el botón o con Enter; usa Shift+Enter para agregar un salto de línea.
  • Activa y desactiva emoji, micrófono, cambio de bot y controles de voz del bot; verifica el evento mostrado.
  • Cambia entre la lista completa de bots y la lista vacía. En una pantalla móvil, recorre también las páginas de bots.
  • Adjunta uno o varios archivos desde la acción o arrástralos a la barra; elimina un archivo y envía el mensaje con sus adjuntos.
  • Alterna input deshabilitado y carga; comprueba que no se pueda escribir ni enviar mientras estén activos.
  • Cambia el placeholder y el icono de emoji; prueba también un placeholder vacío.
